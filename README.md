# ORÁCULO 

Oráculo é um serviço de bot pensado em atender RPG textuais que operam no Discord. É um dos módulos do projeto TRIK (Textual RPG Instituto Kairos), que visa agilizar e facilitar processos dentro de um sistema complexo de jogo. Nessa primeira demo, será apresentado o serviço de **contagem de caracteres** para atendimento de requisitos de tarefas. Ou seja, de maneira automatica e dinamica, o bot será capaz de identificar **qual personagem** está participando das tarefas criadas e contabilizar o processo.
